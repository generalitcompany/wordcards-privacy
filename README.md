# Word Cards — privacy policy

The published privacy policy for the **Word Cards** / **Kelime Kartları** /
**Cartas de Palabras** / **Wortkarten** app, in the four languages the app ships in.

Served by GitHub Pages at <https://generalitcompany.github.io/wordcards-privacy/>.
Google Play requires the policy to be reachable by anyone, without signing in, which
is why this repository is public while the app's own is not.

**These pages are generated.** The four translations live side by side in
`tools/generate_privacy.py` in the app repository, so a change to one claim is visibly
a change to four. Edit them there and regenerate — editing the HTML here puts the
languages out of step with each other and with the next regeneration.
